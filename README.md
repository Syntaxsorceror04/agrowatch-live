# 🌱 AgroEye

AgroEye is an AI-powered invasive species monitoring platform that combines citizen reports, computer vision, and satellite intelligence to enable early detection and rapid response.

### Features

* AI-based invasive species detection
* Geo-tagged citizen reporting
* Satellite-backed verification
* Real-time ecological monitoring
* Government alert and response system

### Tech Stack

* React, TypeScript, Tailwind CSS
* FastAPI, PostgreSQL
* PyTorch, TensorFlow, YOLOv8, EfficientNetV2
* Docker, AWS

### Impact

* 93% species classification accuracy
* 92% ground-satellite fusion accuracy
* 6–12 months earlier detection compared to traditional monitoring
